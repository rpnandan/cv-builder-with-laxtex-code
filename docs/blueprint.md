# **App Name**: ResumeLatex

## Core Features:

- LaTeX Input: Accept LaTeX resume code input.
- AI-Powered Resume Rendering: Leverage an AI tool to compile the LaTeX code and render a visual preview of the resume in various templates.
- Template Display: Display a range of ATS-friendly resume templates generated from the LaTeX code.
- Template Customization: Offer an option to customize and fine-tune templates directly in the app, using LaTeX as a backend.
- PDF Export: Provide functionality to export the generated resume as a PDF file.

## Style Guidelines:

- Primary color: Teal (#008080) for a modern and professional look.
- Background color: Light gray (#F0F8FF) for a clean, minimal design.
- Accent color: Coral (#FF7F50) to draw attention to interactive elements and calls to action.
- Body text: 'Inter', sans-serif, for clean readability.
- Headlines: 'Space Grotesk', sans-serif, for a clean professional feel.
- Use modern, outline-style icons to represent various sections and actions, ensuring they complement the clean and minimal aesthetic.
- Maintain a clean, well-spaced layout with ample whitespace to improve readability. Employ a grid system to keep elements aligned and balanced.
- Incorporate subtle, bouncy animations when transitioning between templates and confirming actions to add a playful touch.
